# Heemsworld

A browser-based 3D character maker built with three.js.

- 99 shirts, 99 pants, 99 jackets, 99 shoes, and 3 sock styles
- Skin tone, hair style and colour, eye colour, height and build
- Export your character as a `.glb` (binary glTF) file

Open `index.html` in a browser, or serve the folder with any static host (e.g. GitHub Pages). No build step.
